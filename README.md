# nexco-mcp

NEXCO 西日本の [高速料金・ルート検索](https://search.w-nexco.co.jp/) で、高速道路の料金・ルート・所要時間を調べる、ローカル用の MCP サーバー（stdio）。
NEXCO 西日本の管轄に限らず、NEXCO 東日本・中日本や首都高・阪神高速などを含む全国の IC 間を調べられる。

> [!IMPORTANT]
> **非公式**のツールです。西日本高速道路株式会社とは関係がありません。
> 公開された API ではなく、サイトの画面と同じやり方で検索しているので、サイトが改修されると動かなくなることがあります。
> 料金はサイトの計算結果をそのまま返します。正式な料金はサイトや料金所で確かめてください。

## ツール

| ツール | 内容 |
|---|---|
| `search_highway_route` | IC から IC までのルートを探す。ルートごとに通常料金（現金）・ETC・ETC2.0 料金、距離、所要時間（渋滞予測込みも）、出発/到着時刻、通る道路と、料金所ごとの料金・ETC 割引（休日・深夜など）、IC・JCT の通過時刻を返す |
| `search_ics` | IC を名前・読みで探す。IC コード、都道府県、道路、出入りの方向の制限（注意書き） |
| `search_roads` | 道路名を探す（`avoid_roads` に渡す名前） |
| `list_drive_passes` | NEXCO 3 社の周遊割引プラン（[みち旅](https://www.michitabi.com/drivepass/)・[速旅](https://hayatabi.c-nexco.co.jp/)・[ドラ割](https://www.driveplaza.com/etc/drawari/)）の一覧。速旅は SA・PA 電子お買物券付プランのような出発エリア別のページも含み、終わったプランは除く。プラン名か URL を渡すと、詳細ページの本文（料金・利用日数・条件）と、乗り放題の範囲の地図・料金表の画像を返す。速旅のページは `section`（例: `M8`, `AN`）でページの中の小さなプランを選ぶ |
| `compare_drive_pass` | 旅程について、通常の ETC 料金と周遊割引プランを使った場合の料金を比べる |

`search_highway_route` の主な引数:

| 引数 | 既定 | 内容 |
|---|---|---|
| `from` / `to` | （必須） | IC 名（「IC」は付けても付けなくてもよい）または IC コード。同名の IC が複数あると候補を返す |
| `via` | なし | 通過 IC（最大 3 つ） |
| `avoid_roads` | なし | 通らない道路（最大 2 つ。例: 中国道, 新名神, 一般道） |
| `date` / `time` | 今（日本時間） | `YYYY-MM-DD` / `HH:MM`。ETC 割引はこの日時で決まる |
| `time_type` | `departure` | `departure`（出発）, `arrival`（到着） |
| `car_type` | `normal` | `kei`（軽・自動二輪）, `normal`（普通車）, `medium`（中型車）, `large`（大型車）, `extra_large`（特大車） |
| `sort` | `time` | `time`（時間順）, `distance`（距離順）, `toll`（通常料金順）, `etc_toll`（ETC 料金順） |
| `count` | `3` | 返すルートの数（1〜5） |
| `include_sapa` | `false` | 区間ごとの SA・PA と通過時刻も返す |

IC の一覧はサイトから読み、12 時間覚えておく。

### 周遊割引プランとの比較

周遊割引プランの乗り放題の範囲（と速旅の料金表）は、ほとんどが画像でしか示されていない。そのため範囲のデータはツールに持たせず、
`list_drive_passes` で画像を見て読み取った料金と、道路と端の IC を、`compare_drive_pass` に渡す。

`compare_drive_pass` の主な引数:

| 引数 | 内容 |
|---|---|
| `legs` | 旅程の区間（`from` / `to` / `date` / `time` / `via`）。一般道だけの移動は入れない |
| `pass_price` | プランの料金（その車種のセット料金・販売価格） |
| `included_value` | セット料金に含まれるお買物券・観光パスポートなどのうち、実際に使う分の金額。その分を差し引いた実質の料金でも比べる |
| `area` | 乗り放題の範囲。道路ごとに `road` と、範囲の端の IC `from` / `to`（道路全体なら両方省く）。範囲が JCT で終わる側は「起点」「終点」と書く |
| `outside_rule` | 範囲の外から入る（外へ出る）区間の範囲外の分の決め方。`route_edge`（既定。ルート上の範囲の端の IC から。速旅など）, `cheapest_ic`（範囲内でいちばん安い IC から。みち旅） |
| `pass_days` | プランの利用日数。旅程の日数が超えると注意を出す |
| `car_type` / `sort` | 車種と、区間ごとのルートの選び方（既定は ETC 料金が安いルート） |

計算のしかた:

- 通常料金は、区間ごとにその日の ETC 割引（休日・深夜など）込みで出す
- プランを使った場合は、プラン料金に範囲外を走る分を足す。範囲の外から入る（外へ出る）区間の範囲外の分は `outside_rule` で決める
- 範囲内かどうかは、IC コードの道路（先頭 4 桁）と道路上の位置（残り 3 桁）で判定する。IC コードの位置は道路の起点から順に増える
- 範囲の外まで走る区間があると、結果に注意を出す。速旅の「発着付き」プランは、往路は周遊エリア内のどこかの IC で一度出て、復路は周遊エリア内の IC から入る決まりで（乗り直す IC は範囲内ならどこでもよい）、範囲の外まで通しで走るとプラン全体が適用されない

例（関西エリア周遊ドライブパスの京都・兵庫プラン）:

```json
{
  "legs": [
    {"from": "中国吹田", "to": "日高神鍋高原", "date": "2026-10-31", "time": "09:00"},
    {"from": "与謝天橋立", "to": "吹田（名神高速）", "date": "2026-11-01", "time": "15:00"}
  ],
  "pass_price": 6300,
  "pass_days": 2,
  "outside_rule": "cheapest_ic",
  "area": [
    {"road": "中国道", "from": "中国吹田", "to": "佐用"},
    {"road": "舞鶴若狭道"},
    {"road": "京都縦貫道"},
    {"road": "山陰近畿道", "from": "与謝天橋立", "to": "京丹後大宮"},
    {"road": "名神", "from": "吹田（名神高速）", "to": "八日市"}
  ]
}
```

→ 通常の ETC 料金 5,310 円（休日割引込み）、プラン 6,600 円（遠阪トンネル 300 円は範囲外）で、通常の方が 1,290 円安い。

例（速旅の SA・PA 電子お買物券付ドライブプラン、首都圏⇒愛知 M8 で東京⇄京都東を平日に往復）:

```json
{
  "legs": [
    {"from": "東京", "to": "京都東", "date": "2026-11-04"},
    {"from": "京都東", "to": "東京", "date": "2026-11-06", "time": "15:00"}
  ],
  "pass_price": 16000,
  "included_value": 5000,
  "pass_days": 3,
  "area": [
    {"road": "東名"},
    {"road": "新東名"},
    {"road": "伊勢湾岸自動車道"},
    {"road": "伊勢湾岸道路"},
    {"road": "東名阪", "from": "名古屋西", "to": "四日市東"},
    {"road": "新名神", "from": "起点", "to": "菰野"},
    {"road": "名神", "from": "小牧", "to": "彦根"}
  ]
}
```

→ 新名神経由で、範囲外の分は菰野〜京都東（片道 2,200 円）。通常の ETC 料金 20,140 円に対し、お買物券を使うなら実質 15,400 円でプランが 4,740 円安い（使わなければ 20,400 円で通常が 260 円安い）。
往路は周遊エリア内の IC で一度出て乗り直す必要がある。

## 使い方

[mise](https://mise.jdx.dev/) で .NET 10 を入れて、単一バイナリを作る。

```bash
mise run publish
```

Claude Code に登録する。

```bash
claude mcp add --scope user nexco -- "$PWD/dist/nexco-mcp"
```

環境変数 `NEXCO_BASE_URL` で接続先を変えられる（テスト用）。
